# Íslenskur tungumálapakki fyrir phpBB 3.3.19

Fullbúin íslensk þýðing fyrir phpBB 3.3.19. Pakkinn nær yfir almenna
spjallborðið, stjórnborð kerfisstjóra, stjórnenda og notenda, uppsetningu,
skipanalínu, hjálparsíður, tölvupóstsniðmát og VigLink-viðbótina sem fylgir
phpBB.

Þýðingin notar íslensku fleirtöluregluna (`15`) og hefur staðist opinbera
phpBB 3.3-prófun án alvarlegra villna, annarra villna eða viðvarana. Allar
textaskrár eru UTF-8 án BOM.

Eldri þýðing Gunnars Guðvarðarsonar fyrir phpBB 3.0.7-PL1 var aðeins endurnýtt
þegar enski frumtextinn hafði ekki breyst eða þegar nákvæm og ótvíræð samsvörun
fannst. Nýr og breyttur texti var þýddur og yfirfarinn fyrir phpBB 3.3.19.
