# Íslenskur tungumálapakki fyrir phpBB 3.3.19

Þessi útgáfa er enn í vinnslu. Skráaskipan og lyklar miðast við phpBB 3.3.19,
en nýr og breyttur texti sem ekki átti örugga samsvörun í eldri íslensku
þýðingunni er enn á breskri ensku og bíður þýðingar og yfirlestrar.

Eldri þýðing Gunnars Guðvarðarsonar fyrir phpBB 3.0.7-PL1 var aðeins endurnýtt
þegar enski frumtextinn hafði ekki breyst.
